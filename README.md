# naryad-ai-frontend

Приложение «Костанайские минералы».

## Структура

- `lib/main.dart` — точка входа.
- `lib/app/` — настройка приложения, маршруты и общие зависимости.
- `lib/core/` — тема и сервисы (фото, звук уведомлений).
- `lib/features/auth/` — вход, регистрация, оформление форм и маска телефона.
- `lib/features/splash/` — стартовый экран.
- `lib/features/master/` — панель мастера.
- `lib/features/orders/` — экраны нарядов, фильтры, канбан и фотографии.
- `lib/features/team/` — бригады.
- `lib/features/reports/` — экраны отчётов, расчёты и представление показателей.
- `lib/shared/` — общие модели, демохранилище и виджеты.
- `lib/l10n/` — русские и казахские переводы и переключение языка.
- `test/` — тесты.

Внутри функций `screens/` содержит экраны, `widgets/` — элементы интерфейса,
`models/` — модели данных. Код будущего интерфейса исполнителя размещается
в `lib/features/executor/`; общие наряды остаются в `orders/`.

## Запуск

```sh
flutter pub get
flutter run
```

Проверки: `flutter analyze` и `flutter test`.
